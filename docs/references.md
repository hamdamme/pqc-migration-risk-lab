# References

Primary standards and project references consulted for the scope and terminology:

1. NIST, [FIPS 203: Module-Lattice-Based Key-Encapsulation Mechanism Standard](https://csrc.nist.gov/pubs/fips/203/final). Defines ML-KEM for key establishment. Check NIST errata and updates before implementation decisions.
2. NIST, [FIPS 204: Module-Lattice-Based Digital Signature Standard](https://csrc.nist.gov/pubs/fips/204/final). Defines ML-DSA digital signatures.
3. NIST, [FIPS 205: Stateless Hash-Based Digital Signature Standard](https://csrc.nist.gov/pubs/fips/205/final). Defines SLH-DSA digital signatures.
4. NIST, [SP 800-227: Recommendations for Key-Encapsulation Mechanisms](https://csrc.nist.gov/pubs/sp/800/227/final).
5. NIST NCCoE, [Migration to Post-Quantum Cryptography](https://www.nccoe.nist.gov/applied-cryptography/migration-to-pqc).
6. CycloneDX, [Cryptography Bill of Materials (CBOM) guide](https://cyclonedx.org/guides/OWASP_CycloneDX-Authoritative-Guide-to-CBOM-en.pdf) and [specification repository](https://github.com/CycloneDX/specification).
7. MITRE, Moses Liskov, *The Six Phases of Cryptographic Migration* (presentation discussed as project inspiration).
8. Nicolas Gama (SandboxAQ) and Basil Hess (IBM Research), presentations discussed as inspiration for context-aware cryptographic inventories and cryptographic behavior.

The project is not affiliated with or endorsed by NIST, MITRE, SandboxAQ, IBM Research, CycloneDX, or CBOMkit. The named talks are conceptual motivation, not source text reproduced here. Verify current standards and errata directly with their publishers.
